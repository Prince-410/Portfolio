## 💫 Features

- **🎨 Modern Glassmorphism UI:** Features premium, futuristic styling with customizable glowing accents, dark/light backdrop blur filters, and dynamic layout cards.
- **✨ Micro-Animations:** Loaded with interactive elements, custom scroll behaviors, magnetic button interactions, dynamic typewriter loops, and smooth section transitions.

## ⚙️ Getting Started (Local Development)

To run and view this project locally, execute the following steps:

1. **Clone the Repository**
   ```bash
   git clone https://github.com/Prince-410/Portfolio.git
   cd Portfolio
   ```

2. **Serve Locally**
   You can run it using any simple HTTP server, or the VS Code Live Server extension. Alternatively, run using Node:
   ```bash
   # Using npx to serve the directory
   npx serve .
   ```

3. **Open Browser**
   Access the local server page via the URL output by the server tool (usually `http://localhost:3000` or `http://127.0.0.1:5500`).

## 🌐 Deployment

The site is configured for automatic CI/CD deployment via **Vercel**. Every commit pushed to the main branch is automatically compiled and hosted live. 

To run production tests locally using Vercel CLI:
```bash
# Log in and deploy a preview
vercel

# Deploy to production
vercel --prod
```
